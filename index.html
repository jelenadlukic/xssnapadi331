Lekcija: DOM manipulacija

Šta je DOM?

DOM predstavlja strukturu HTML dokumenta koju JavaScript može da čita i menja.

Element možemo pronaći pomoću metode getElementById().

const naslov = document.getElementById("naslov");

Nakon toga možemo promeniti njegov sadržaj.

naslov.textContent = "Novi naslov";

innerHTML

Svojstvo innerHTML omogućava da JavaScript ubaci HTML sadržaj u element.

element.innerHTML = "<b>Zdravo</b>";

Browser će ovaj sadržaj protumačiti kao HTML.

Primer događaja

button.addEventListener("click", function() { alert("Kliknuli ste dugme!"); });
